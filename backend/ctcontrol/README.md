# CTControl
Gerencia alunos e suas mensalidades. 

## Sobre o CTControl

Um dos grandes desafios que gestores de centro de treinamento (CT), é o de controlar, alunos e as suas mensalidades. O CTControl, está sendo criado com o intuito de facilitar a vida dos mesmos. CTControl controla os alunos, cadastros e matriculas, mas o seu diferencial está na abordagem das mensalidades, cada aluno tem a sua mensalidade e data de pagamento correta, ao passar dessa data, o sistema vai permitir enviar uma notificação de atrasso para o aluno pendente. Com isso evitando transtornos para o gestor ou professor. 

## Tecnologias 
- UML
- Java
- Sring Boot
- JWT
- MySql


## Funcionalidades

### Prontas

- **CRUD de Alunos, Mensalidades e Turmas:** Criação, edição e remoção, utilizando protócolos HTTP.
- **Matricula de aluno:** Permite adcionar alunos em uma turma.
- **Mudança no status da mensalide de forma automática:** Muda o status da mensalidade para pendente.
- **Autenticação e geração de Token:** Cria um token a parti de uma senha do usuário
